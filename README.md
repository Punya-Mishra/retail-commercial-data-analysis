# Retail Commercial Data Analysis

This project explores how machine learning can generate commercial insights from publicly available retail datasets, using the **Commercial Data Analyst role at Coles Group** as the industry context.

## Project Overview

The analysis uses two public retail datasets to investigate customer purchasing behaviour and identify patterns that could support commercial decision-making.

The project applies:

* **Logistic Regression**
* **Random Forest**

The models are evaluated using:

* Accuracy
* F1-score
* ROC-AUC

The findings from both datasets are compared to determine whether they provide complementary insights relevant to retail analytics.
